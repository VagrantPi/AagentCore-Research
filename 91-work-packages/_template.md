# 回填模板

複製到各 WP 檔案最下方的「回填」區。每一欄都要填，沒有就寫「無」。

```markdown
## 回填

- 負責人：
- 執行日期：
- 區域：
- 資源 tag：`wp=WPx`、`owner=<人>`
- 使用的 AWS 帳號：

### 結論（三句內）

1.
2.
3.

### 檢核表

| # | 檢核點 | 來源等級 | 結果 | 證據 | 對選型的影響 |
|---|---|---|---|---|---|
| 1 | | `[官方已寫]` / `[推測]` / `[矛盾]` | 通過 / 否定 / 無法驗證 | 指令、截圖路徑、log 路徑、API 回應 | |

- 「無法驗證」要寫原因（配額、權限、功能未開放到該區域……）。
- `[矛盾]` 的項目要寫出哪一頁文件是對的，附 URL。

### 實際費用

| 資源 | 用量（時數、次數） | Cost Explorer 金額（USD） | 估算金額（若有） | 差異說明 |
|---|---|---|---|---|

- Cost Explorer 有約 24 小時延遲，執行隔天再拉一次，以隔天的數字為準。
- 拉法見 [WP0](WP0-cost-baseline.md)。

### 否定項目的替代方案

| 被否定的檢核點 | 替代方案 | 多出的成本或限制 |
|---|---|---|

### 清理確認

- [ ] Runtime / Harness 已刪除
- [ ] Browser session 已停止、profile 已刪除
- [ ] Gateway、Policy 已刪除
- [ ] Memory 已刪除
- [ ] VPC endpoint、NAT 已刪除
- [ ] 隔天確認 Cost Explorer 無持續計費

### 要更正研究庫的段落

| 檔案:行號 | 原本寫的 | 實測結果 |
|---|---|---|
```
